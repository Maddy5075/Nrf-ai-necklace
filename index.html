Keep this tab in the foreground. Android throttles background timers, which stalls the paced speaker downlink mid-playback.
Pairing. A stock image requires an encrypted link and Web Bluetooth cannot pair, so the bond has to come from the operating system. Connect anyway — the console detects the requirement and walks you through it.

Pairing required

The necklace refused an unencrypted link. Web Bluetooth has no passkey-entry UI and no API to trigger one, so the bond has to be created by the operating system. You do this once — both sides persist it, and the necklace keeps it across the reboot that every wake from deep sleep performs.
Passkey—
    The console has released the link so the OS can reach the device. The necklace allows one connection at a time, so holding this one open would block the pairing you are about to do — and the firmware would drop it anyway after its security timeout.
    Bench alternative: flash an image built with overlay-ble-open.conf, which removes the requirement. That image has a live microphone readable by anything in range — bench, not body.
